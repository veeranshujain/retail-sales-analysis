# Retail Sales Analysis: Identifying Revenue Trends & Business Opportunities

## Overview
An exploratory data analysis project using the Sample Superstore dataset to identify sales trends, profitability patterns, and business opportunities.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL (SQLite)
- Jupyter Notebook

## Dataset
Sample Superstore dataset from Kaggle.

## Project Objectives
- Analyze overall sales and profitability.
- Identify top-performing and low-performing product categories.
- Examine regional sales performance.
- Analyze monthly and yearly sales trends.
- Understand the relationship between discounts and profitability.
- Identify customer contribution and profitability patterns.
